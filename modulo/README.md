# Módulo de Edición con IA · Mapa

Parte de la formación DECODIK. Para todos los talentos, sin conocimientos previos.

Cada lección responde a tres preguntas:
1. **¿Qué podrás hacer** después de esta lección?
2. **¿Cómo lo aplicas** a tu contenido?
3. **¿Cómo te ayuda** a trabajar con marcas?

Formato de cada lección: **vídeo Loom corto (4-8 min) + transcripción + resumen en texto + reto**. El reto se publica en la comunidad DECODIK.

## Nivel 1 · Usar (sin terminal)
| # | Lección | Resultado | Skill |
|---|---|---|---|
| 1.1 | El flujo de contenido con IA | Entiendes las 6 fases: idea → plantilla → guion → grabar → editar → revisar | — |
| 1.2 | Configura Claude y tu perfil | Skills instaladas, proyecto creado, `perfil-talento.md` listo | `decodik-perfil` |
| 1.3 | Del tema al gancho | Eliges plantilla y tienes guion + 3 ganchos con tu voz | `decodik-edicion` |

| 1.6 | Subtítulos, ritmo y sonido | Vídeo con Sello DECODIK | `decodik-edicion` |
| 1.7 | Entrega a una marca | Brief ordenado, revisión contra el brief y mensaje de entrega | `decodik-marca` |
